# Asset 素材库 API · Seedance 2.0<br /><br />本文介绍西湖云平台 Asset 素材库与 Seedance 2.0 视频生成 API。所有示例使用平台 API Key，不直接调用火山方舟原生接口。<br /><br />## 环境准备<br /><br />    export BASE_URL="https://ai.xihuyun.com"<br />    export API_KEY="sk-替换为你的平台 API Key"<br /><br />请求头：<br /><br />    Authorization: Bearer \<API_KEY><br /><br />API Key 必须属于已启用用户并拥有目标模型权限。不要将真实 Key 写入前端、公开仓库或日志。<br /><br />## 调用流程<br /><br />1. 使用 POST /v1/assets 上传或导入素材。<br />2. 读取响应中的完整 data.asset_uri，格式为 asset://...。<br />3. 将 Asset URI 放入 Seedance 请求的 images、reference_inputs 或 content[]。<br />4. 保存平台返回的任务 ID，轮询状态并下载结果。<br /><br />## Asset 素材库 API<br /><br />素材属于当前 API Key 对应的用户。上传和导入需要文件上传权限，并传入 agreed=true。<br /><br />| 功能 | 方法与路径 | 说明 |<br />| --- | --- | --- |<br />| 本地上传 | POST /v1/assets | multipart 字段 file、agreed=true，可重复传多个 file |<br />| 在线导入 | POST /v1/assets/import | JSON 字段 url，可选 name、asset_type、folder_id |<br />| 查询列表 | GET /v1/assets | 支持 p、page_size、folder_id |<br />| 查询详情 | GET /v1/assets/\{asset_id\} | 查询当前用户自己的素材 |<br />| 删除素材 | DELETE /v1/assets/\{asset_id\} | 删除当前用户自己的素材 |<br />| 恢复素材 | POST /v1/assets/\{asset_id\}/restore | 归档素材恢复需要长期存储权益 |<br />| 文件夹 | GET/POST /v1/assets/folders | 查询或创建文件夹 |<br />| 文件夹管理 | PATCH/DELETE /v1/assets/folders/\{folder_id\} | 重命名或删除文件夹 |<br />| 移动素材 | PATCH /v1/assets/\{asset_id\}/folder | JSON 传 folder_id |<br /><br />### 上传本地素材<br /><br />    curl -X POST "\$BASE_URL/v1/assets" \\<br />      -H "Authorization: Bearer \$API_KEY" \\<br />      -F "file=@./reference.png" \\<br />      -F "agreed=true"<br /><br />支持扩展名：图片 jpg/jpeg/png/webp/gif/bmp；视频 mp4/mov/webm/mkv/avi/m4v；音频 mp3/wav/m4a/aac/flac/ogg。<br /><br />成功响应：<br /><br />    \{"success":true,"data":\{"asset_id":"xhy_xxxxxxxxx","asset_uri":"asset://xhy_xxxxxxxxx","asset":\{"asset_type":"Image","status":"Active"\}\}\}<br /><br />后续请求必须使用完整 data.asset_uri。不要自行拼接 ID，也不要使用对象存储 URL或预览 URL作为 Asset 引用。<br /><br />### 在线导入<br /><br />    curl -X POST "\$BASE_URL/v1/assets/import" \\<br />      -H "Authorization: Bearer \$API_KEY" \\<br />      -H "Content-Type: application/json" \\<br />      -d '\{"url":"https://example.com/reference.png","name":"reference.png","asset_type":"Image","agreed":true\}'<br /><br />服务端必须能够访问在线地址；地址失效、扩展名不支持或下载失败都会导致导入失败。<br /><br />## Seedance 2.0 视频生成<br /><br />### 推荐入口：POST /v1/videos<br /><br />    curl -X POST "\$BASE_URL/v1/videos" \\<br />      -H "Authorization: Bearer \$API_KEY" \\<br />      -H "Content-Type: application/json" \\<br />      -d '\{"model":"seedance-2.0","prompt":"让参考图片中的人物自然地转身并向镜头挥手。","images":["asset://xhy_xxxxxxxxx"],"duration":4,"resolution":"480p","ratio":"3:4","generate_audio":true\}'<br /><br />创建请求返回异步任务。查询：<br /><br />    curl "\$BASE_URL/v1/videos/task_xxxxxxxxx" -H "Authorization: Bearer \$API_KEY"<br /><br />### 原生多模态入口<br /><br />POST /v1/video/generations 支持 content[]，可使用 image_url、video_url、audio_url，并标记 reference_image、first_frame、last_frame、reference_video 或 reference_audio。prompt 必须放在请求顶层，不能只写在 content 中。<br /><br />### Seedance 2.0 平台规则<br /><br />- 图片参考最多 9 张，视频参考最多 3 个，音频参考最多 3 个。<br />- 音频参考必须同时存在图片或视频参考。<br />- 当前只支持单输出，n 如传入必须为 1。<br />- 支持首帧和尾帧，具体组合以当前渠道能力为准。<br />- 不要传 output_format、seed、fps、motion、negative_prompt、frames、camera_fixed、service_tier 等 Seedance 2.0 不支持的字段。<br />- Seedance 2.5 的 30 张图片、10 个视频、10 个音频及 4～30 秒规则只适用于 2.5，不要套用到 2.0。<br /><br />## 任务列表、取消与下载<br /><br />任务状态通常包括 queued、in_progress、completed、succeeded、failed、cancelled。建议每 2～5 秒查询一次；任务提交成功后不要重复创建。<br /><br />任务列表要求指定当前用户拥有的任务 ID，并提供模型筛选：<br /><br />    curl "\$BASE_URL/v1/videos?filter.task_ids=task_xxxxxxxxx&filter.model=seedance-2.0" -H "Authorization: Bearer \$API_KEY"<br /><br />取消或删除任务：<br /><br />    curl -X DELETE "\$BASE_URL/v1/videos/task_xxxxxxxxx" -H "Authorization: Bearer \$API_KEY"<br /><br />下载已完成视频：<br /><br />    curl "\$BASE_URL/v1/videos/task_xxxxxxxxx/content" -H "Authorization: Bearer \$API_KEY" -o output.mp4<br /><br />## 常见错误<br /><br />| HTTP 状态 | 处理建议 |<br />| --- | --- |<br />| 401 | 检查 Bearer API Key 是否有效 |<br />| 403 | 检查用户、分组、模型权限和上传权限 |<br />| 400 | 检查 prompt、素材 URI、模型字段和不支持参数 |<br />| 404 | 检查 Asset ID 或平台任务 ID |<br />| 413 | 文件超过平台上传大小限制 |<br />| 429 | 降低请求频率并退避重试 |<br />| 5xx | 记录请求信息后有限重试，不要盲目重复创建任务 |<br /><br />## Python 示例<br /><br />    python3 docs/examples/seedance2_platform.py generate --image ./reference.png --prompt '让图片中的人物自然地走向镜头。' --model seedance-2.0 --duration 4 --resolution 480p --ratio 3:4 --wait<br /><br
