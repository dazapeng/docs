本文介绍西湖云平台 Asset 素材库与 Seedance 2.0 视频生成 API。所有示例使用平台 API Key。

## 环境准备

```bash
export BASE_URL="https://ai.xihuyun.com"
export API_KEY="sk-替换为你的平台 API Key"
```

请求头：

`Authorization: Bearer <API_KEY>`

## 调用流程

1. 使用 `POST /v1/assets` 上传或导入素材。
2. 读取响应中的完整 `data.asset_uri`，格式为 `asset://...`。
3. 将 Asset URI 放入 Seedance 请求的 `images`、`reference_inputs` 或 `content[]`。
4. 保存任务 ID，轮询状态并下载结果。

## Asset 素材库 API

| 功能 | 方法与路径 | 说明 |
| --- | --- | --- |
| 本地上传 | `POST /v1/assets` | multipart：file、agreed=true |
| 在线导入 | `POST /v1/assets/import` | JSON：url、name、asset_type、folder_id |
| 查询列表 | `GET /v1/assets` | 支持 p、page_size、folder_id |
| 查询详情 | `GET /v1/assets/{asset_id}` | 查询当前用户自己的素材 |
| 删除素材 | `DELETE /v1/assets/{asset_id}` | 删除当前用户自己的素材 |
| 恢复素材 | `POST /v1/assets/{asset_id}/restore` | 恢复归档素材 |
| 文件夹 | `GET/POST /v1/assets/folders` | 查询或创建文件夹 |
| 移动素材 | `PATCH /v1/assets/{asset_id}/folder` | JSON 传 folder_id |

### 上传本地素材

```bash
curl -X POST "$BASE_URL/v1/assets" \
  -H "Authorization: Bearer $API_KEY" \
  -F "file=@./reference.png" \
  -F "agreed=true"
```

支持图片 jpg/jpeg/png/webp/gif/bmp；视频 mp4/mov/webm/mkv/avi/m4v；音频 mp3/wav/m4a/aac/flac/ogg。

### 在线导入

```bash
curl -X POST "$BASE_URL/v1/assets/import" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/reference.png","name":"reference.png","asset_type":"Image","agreed":true}'
```

后续请求必须使用完整的 `data.asset_uri`，不要自行拼接 ID，也不要使用对象存储 URL 或预览 URL。

## Seedance 2.0 视频生成

### 推荐入口：`POST /v1/videos`

```bash
curl -X POST "$BASE_URL/v1/videos" \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"seedance-2.0","prompt":"让参考图片中的人物自然地转身并向镜头挥手。","images":["asset://xhy_xxxxxxxxx"],"duration":4,"resolution":"480p","ratio":"3:4","generate_audio":true}'
```

查询任务：`GET /v1/videos/{task_id}`。多模态入口为 `POST /v1/video/generations`，prompt 必须放在请求顶层。

### 平台规则

- 图片参考最多 9 张，视频参考最多 3 个，音频参考最多 3 个。
- 音频参考必须同时存在图片或视频参考。
- 当前只支持单输出，n 如传入必须为 1。
- 支持首帧和尾帧，具体组合以当前渠道能力为准。
- 不要传 output_format、seed、fps、motion、negative_prompt、frames、camera_fixed、service_tier 等不支持字段。
- Seedance 2.5 的数量和时长规则不适用于 2.0。

## 任务查询、取消与下载

```bash
curl "$BASE_URL/v1/videos?filter.task_ids=task_xxxxxxxxx&filter.model=seedance-2.0" -H "Authorization: Bearer $API_KEY"

curl -X DELETE "$BASE_URL/v1/videos/task_xxxxxxxxx" -H "Authorization: Bearer $API_KEY"

curl "$BASE_URL/v1/videos/task_xxxxxxxxx/content" -H "Authorization: Bearer $API_KEY" -o output.mp4
```

## 常见错误

| HTTP 状态 | 处理建议 |
| --- | --- |
| 401 | 检查 Bearer API Key |
| 403 | 检查用户、分组、模型及上传权限 |
| 400 | 检查 prompt、素材 URI 和参数 |
| 404 | 检查 Asset ID 或任务 ID |
| 413 | 文件超过平台上传大小限制 |
| 429 | 降低请求频率并退避重试 |
| 5xx | 有限重试，不要重复创建任务 |
